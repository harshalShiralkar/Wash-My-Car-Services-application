# 🚗 Wash My Car Services

A modern and responsive **car wash and detailing service web application** built using HTML, CSS, and JavaScript.

The application provides a user-friendly interface for customers to explore car wash services, book appointments, and view billing information.

## ✨ Features

* 🔐 **User Login**

  * Email and password login
  * Registration interface
  * Google sign-in interface

* 🏠 **Dashboard**

  * Premium car care overview
  * Quick actions
  * Recent activity
  * Service statistics

* 🚿 **Car Wash Services**

  * Express Wash
  * Premium Wash
  * Full Detail
  * Ceramic Coating
  * Monthly Unlimited Plan
  * Add-on services

* 📅 **Appointment Booking**

  * Select a service
  * Choose date and time
  * Enter vehicle details
  * Review booking summary
  * Select payment method
  * Confirm booking

* 💳 **Billing**

  * Invoice history
  * Payment method section
  * Total spending
  * Loyalty points
  * Pending payments

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Google Fonts**



## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the dashboard, services, booking, and billing sections.

No server or database is required for the current demo version.

## 📱 Responsive Design

The interface is designed to work across different screen sizes, with responsive layouts for booking and billing sections and a mobile-friendly navigation experience.

## 🎯 Project Purpose

This project demonstrates the development of a **car wash service management interface** with multiple interactive sections and a modern dashboard-style UI.

It can be used as a starting point for a larger application with a backend, database, authentication system, and real payment integration.
